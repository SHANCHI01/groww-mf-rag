# PRD: Groww MF Facts-Only RAG Assistant
**Goal:** answer factual questions about 5 Groww schemes (Large Cap, ELSS, Aggressive Hybrid, Value, Multicap) from public pages, each with one source link.
**Users:** retail investors comparing schemes; support/content teams.
**In scope:** expense ratio, exit load, min SIP, ELSS lock-in, riskometer, benchmark; refusal of advice/performance/PII questions; 10-message memory; Weekly Pulse (Milestone 5).
**Out of scope:** advice, return calculations, PII storage, portfolio questions, non-Groww funds.
**Success:** answers <=3 sentences, one link, "Last updated from sources", correct refusals, runs locally and on Render, free-tier tools only.
**Example questions:** "Expense ratio of Groww Large Cap?", "ELSS lock-in?", "Exit load of Small Cap?"
